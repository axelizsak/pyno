Pyno

Live speech-to-text on your Mac. Fully local, free, no account.

Built for lecture halls. Start it when the lecturer starts, stop it at the end, walk out with the hour already written up.

What it does

Nothing leaves the machine
Transcription runs on the Apple Neural Engine, not a server. No account, no subscription, no upload. It works exactly the same with the Wi-Fi off.
Long sessions are the normal case
Two and three hour recordings are what it was tuned for. The transcript is written to disk as it goes, so a crash costs a paragraph, not a lecture.
You end up with plain Markdown
One file per session in your Documents folder. Read it, move it, rename it, or hand it to Claude for a summary. There is no database and no lock-in.
It speaks 25 European languages
NVIDIA Parakeet TDT v3 through Core ML. The interface follows the language you pick, in English or French.

Getting started

  1. Open the disk image and drag Pyno to Applications.
  2. Allow the microphone when macOS asks on first launch.
  3. Wait once while the speech model downloads, about 470 MB. Everything after that is offline and instant.
